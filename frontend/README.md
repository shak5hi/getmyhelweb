# GetMyHelp: website

This folder is the Next.js app for [getmyhelp.in](https://getmyhelp.in).

Setup, environment variables, project structure and deployment are documented in the [main README](../README.md). First-time server setup is in [VPS_SETUP_GUIDE.md](VPS_SETUP_GUIDE.md).

```bash
npm install
cp .env.example .env.local
npm run dev   # http://localhost:3006
```
